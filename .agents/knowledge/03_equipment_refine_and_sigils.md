# 03 — ระบบอุปกรณ์สวมใส่ 11 ชิ้น, ค่า Perfection (0-100), เซ็ตคราฟท์ NPC แต้มทะลุหลอด, ออปชันม่วง, ข้อจำกัดสเตตัส, Refine (0-30) และ Sigils

เอกสารนี้กำหนดรายละเอียดเชิงลึกของอุปกรณ์สวมใส่ทุกประเภทในเกม เพื่อให้ระบบคำนวณค่าสเตตัสตรงตามตัวเลขจริงในเกมทุกจุด

---

## 1. ช่องอุปกรณ์สวมใส่ทั้ง 11 ช่อง (11 Equipment Slots)
ได้แก่: `weapon` (อาวุธ), `head` (หมวก), `chest` (ชุด), `gloves` (ถุงมือ), `boots` (รองเท้า), `earrings` (ต่างหู), `necklace` (สร้อยคอ), `ring` (แหวน), `bracelet_left` (กำไลซ้าย), `bracelet_right` (กำไลขวา), และ `charm` (เครื่องราง)

---

## 2. ระบบค่าความสมบูรณ์ของอุปกรณ์: Perfection / Perfect Value (0 ถึง 100)

อุปกรณ์ที่ดรอปจากแมพ/ดันเจี้ยนหรือคราฟท์ปกติ จะมีค่าระดับความสมบูรณ์ (**Perfection / Perfect Value**) กำหนดได้ตั้งแต่ **`0` ถึง `100`**:
* **สมการการคำนวณสเตตัสตามค่า Perfect (0 - 100):**
  * อุปกรณ์แต่ละชิ้นในแต่ละเลเวลจะมีค่าสเตตัสเริ่มต้นที่ Perfect 0 (`minStatValue`) และค่าสเตตัสสูงสุดที่ Perfect 100 (`maxStatValue`)
  * เมื่อผู้ใช้เลื่อนปรับค่า `perfection` ($P \in [0, 100]$) ค่าสเตตัสของอุปกรณ์ชิ้นนั้นจะคำนวณจาก:
    $$\text{Stat}(P) = \left\lfloor \text{Stat}_{\min} + \left( \text{Stat}_{\max} - \text{Stat}_{\min} \right) \times \left( \frac{P}{100} \right) \right\rfloor$$
  * การเพิ่มค่า Perfect จาก 0 ไปจนถึง 100 จะส่งผลโดยตรงต่อแต้มของ **สเตตัสหลัก (Main Stat)**, **สเตตัสรอง (Sub Stat)** และ **สเตตัสเสริม (Extra Stat)** ของอุปกรณ์ชิ้นนั้น

---

## 3. ความแตกต่างระหว่าง "อุปกรณ์ทั่วไป/ดรอปแมพ" vs "อุปกรณ์เซ็ตคราฟท์จากร้านเฉพาะ (NPC Set Gear)"

ใน Simulator ผู้ใช้ต้องสามารถเลือกประเภทอุปกรณ์ในแต่ละช่องได้ ซึ่งมีกฎของสเตตัสต่างกันอย่างชัดเจนดังนี้:

### 3.1 อุปกรณ์ดรอปจากแมพ / ดันเจี้ยน และอุปกรณ์คราฟท์ Life Skill (Non-Set Gear)
* **การเลือกสเตตัส:** ผู้ใช้สามารถเลือกปรับแต่งชนิดของสเตตัสหลัก+รอง+เสริม ได้ตามรายการที่อนุญาตของชิ้นนั้น และปรับค่า **Perfection (0 - 100)** ได้
* **ออปชันม่วง (Purple Bonus Stat / Rare Attribute):**
  * อุปกรณ์ที่ไม่ใช่เซ็ต (Non-Set Gear) สามารถเลือกใส่ **ออปชันสีม่วง (Purple Stat)** ได้ 1 แถว
  * รายการออปชันม่วงที่พบได้จะขึ้นอยู่กับช่องอุปกรณ์ (เช่น อาวุธ/เครื่องประดับ/ชุดเกราะ) ได้แก่: `PHY Boost %`, `MAG Boost %`, `Attack SPD %`, `Cast Speed %`, `CritDMG %`, `Lucky Strike DMG Multiplier %`, `All-Element Bonus %`, `Fire/Ice/Forest/Thunder/Wind/Rock/Light/Dark Bonus %`, `Healing Output %`, `Shield %`, `ATK Reduction %`, `MATK Reduction %`, `Block DMG Reduction %`, `Illusion-Breaking Strength` เป็นต้น
* **ไม่มีเอฟเฟกต์เซ็ต 2 ชิ้น / 4 ชิ้น**

### 3.2 อุปกรณ์เซ็ตที่สร้างจาก NPC / ร้านแลกเฉพาะ และไอเทมเฉพาะ (Special NPC Set Gear)
* **ลักษณะพิเศษของสเตตัส (Locked Stat Types with Over-capped Values):**
  1. **ล็อกประเภทสเตตัสตายตัว:** อุปกรณ์เซ็ตแต่ละชิ้นจะกำหนดตายตัวเลยว่าให้สเตตัสตัวไหน (ไม่สามารถเปลี่ยนชนิดสเตตัสรองตามใจชอบเหมือนของดรอปแมพ)
  2. **ให้แต้มพลังทะลุหลอด (Over-capped Stats):** ค่าสเตตัสของอุปกรณ์เซ็ตจะมีแต้มสูงทะลุเพดาน `Perfect 100` ของอุปกรณ์ดรอปแมพในเลเวลเดียวกัน!
  3. **ไม่มีออปชันม่วงสุ่มทั่วไป** แต่ทดแทนด้วยแต้มสเตตัสที่ทะลุหลอดและ **เอฟเฟกต์เซ็ต (Set Bonuses)**
* **เอฟเฟกต์เมื่อสวมใส่ครบเซ็ต (Set Effects):**
  * แยกตามสายอาชีพและบทบาทของเซ็ตนั้นๆ:
    - **ใส่ครบ 2 ชิ้น (2-Piece Set Bonus):** มอบโบนัสสเตตัสหรือเพิ่ม `% ดาเมจ / % ฮีล / % ป้องกัน` ขั้นต้น
    - **ใส่ครบ 4 ชิ้น (4-Piece Set Bonus):** มอบเอฟเฟกต์ทรงพลังที่ทำงานในการต่อสู้ (เช่น เมื่อใช้สกิลหลักหรือติด Crit/Luck จะได้รับบัฟตัวคูณดาเมจ/ความเร็ว หรือปลดปล่อยดาเมจเสริม)

### 3.3 อาวุธพิเศษ (Epic Weapons & Far Sea Weapons)
* **อาวุธ Epic:** อาวุธที่มีเอฟเฟกต์พาสซีฟเฉพาะตัวประจำอาชีพ
* **อาวุธ Far Sea (远海武器):** อาวุธระดับสูงสุดที่มีสเตตัสทะลุหลอดและมีเอฟเฟกต์พิเศษเฉพาะตัวที่ทรงพลังมากในการคำนวณ DPS/HPS

---

## 4. ตารางข้อจำกัดสเตตัสแยกตามสายอาชีพและชิ้นอุปกรณ์ (Slot Stat Restriction Matrix)

อุปกรณ์ของแต่ละสายสเตตัสหลัก (**สาย Agility**, **สาย Strength**, **สาย Intellect**) มีกฎเหล็กว่า **ในอุปกรณ์แต่ละชิ้น (จากทั้ง 11 ชิ้น) จะมีค่าสเตตัสบางตัวที่ "ไม่สามารถสุ่มออก / หาไม่ได้" จากอุปกรณ์ชิ้นนั้นเด็ดขาด**:
* ระบบฐานข้อมูล `/src/data/game-db/equipments/slot-restrictions.json` ต้องเก็บ Mapping แยกตาม:
  `[PrimaryStatClass: "strength" | "agility" | "intellect"][SlotId: EquipmentSlot]` $\rightarrow$ `{ allowedSubStats: AttributeKey[], forbiddenSubStats: AttributeKey[], allowedPurpleStats: AttributeKey[] }`
* เมื่อผู้ใช้เลือกสายอาชีพแล้วคลิกที่ช่องอุปกรณ์ใดๆ ในหน้า UI ตัว Dropdown จะแสดงเฉพาะสเตตัสที่หาได้จริงในชิ้นนั้นเท่านั้น

---

## 5. ระบบการตีบวก Refine (0 ถึง 30) และระบบ Sigils (Emblem Lv.1, Lv.2, Lv.3)
* **Refine (0 - 30):** เลือกตั้งค่าระดับ Refine แยกรายชิ้น (0-30) บวกค่าสเตตัสเสริมและเพิ่ม `Refined ATK`, `Refined MATK`, `Refined Armor` ตามตารางเลเวล Refine
* **Sigils (Lv.1 - 3):** เลือก Sigil 1 ชิ้นต่อ 1 อุปกรณ์ (กรองตาม `allowedSlots` ของ Sigil ชิ้นนั้น) และเลือกระดับการฝัง **Emblem Lv.1, Lv.2 หรือ Lv.3** เพื่อบวกค่าสเตตัสตามระดับที่เลือก
